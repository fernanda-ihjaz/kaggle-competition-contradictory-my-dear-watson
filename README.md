# Contradictory, My Dear Watson

Trabalho prático de Machine Learning (UPF) sobre o desafio [Contradictory, My Dear Watson](https://www.kaggle.com/competitions/contradictory-my-dear-watson) do Kaggle. A tarefa é inferência textual multilíngue: para cada par premissa e hipótese, prever se a relação é entailment (0), neutral (1) ou contradiction (2). A métrica oficial é a acurácia.
